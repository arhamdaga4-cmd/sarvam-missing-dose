What this page is: a working model of the agent's flow running entirely in your browser — scripted agent lines, your answers, and a real rule engine deciding escalation. It does not call any API or phone number. The shipped agent uses Sarvam's Saaras v4 for speech, Bulbul v3 for voice and Sarvam-105B for the dialogue; the How it works page and the repository show that code.
