Live mode. Paste your Sarvam subscription key above and the page talks to Sarvam directly from your browser: sarvam-105b-conversations for the dialogue, bulbul:v3 for the voice, saaras:v4 for your speech. The key is stored in this browser's local storage and never leaves it — but anything stored in a browser can be read on that device, so use a throwaway key here and keep real patient calls on the server deployment in the repository. Without a key the page falls back to a scripted demo so you can still see the flow.
